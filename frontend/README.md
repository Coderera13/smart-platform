# Smart Project

A full-stack smart interview/test platform built with Spring Boot and React.

## Features

- JWT Authentication
- Role-based access
- Question CRUD
- Test CRUD
- Test attempts
- Auto-scoring
- Analytics
- Leaderboard

## Tech Stack

- Spring Boot
- Spring Security
- JWT
- MySQL
- React
- Axios
- React Router

## Setup

### Backend

1. Configure MySQL database.
2. Update `application.properties`.
3. Run the Spring Boot application.

### Frontend

1. Install dependencies.
2. Run the Vite app.
